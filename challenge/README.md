# Fix My Code Challenge

The goal is to fix existing code bases in different programming languages without completely rewriting them.

## 📌 Background

In this project, we are provided with broken code in different languages (Python, JavaScript, Ruby, C, etc.).  
Instead of rewriting everything, we are expected to:

- Identify what is wrong
- Fix only the necessary parts
- Ensure the code works as expected
- Respect original structure as much as possible

This simulates real-world debugging scenarios where developers work on legacy code.

---

## 📁 Project Structure

| File / Folder | Language | Description |
|---------------|----------|-------------|
| `0-fizzbuzz.py` | Python | Fixes FizzBuzz logic so that numbers divisible by 3 and 5 print "FizzBuzz" correctly |
| `1-print_square.js` | JavaScript | Fixes square printing using Node.js and correct argument parsing |
| `2-sort.rb` | Ruby | Fixes sorting of command-line arguments in numeric order |
| `3-user.py` | Python | Fixes User class password validation method |
| `4-delete_dnodeint/` | C | Fixes deletion logic in a doubly linked list implementation |

---

## 🚀 Objective

The main objective of this project is to improve debugging skills across multiple programming languages by:

- Understanding existing code quickly
- Identifying logical and runtime errors
- Applying minimal but effective fixes
- Ensuring correct output behavior
